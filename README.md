# Semi-Random Commander Search

This is an app that is designed to take the Random Commander website and expand upon its functionality.

It utilizes the Scryfall API for the data, React for the front-end and Flask for the back-end to deliver a single valid commander option based on criteria provided by the user.

# Start the server.

First enter the venv environment.

On Windows Command Line: 

In the api directory:
venv/Scripts/activate

Then go up a level and in the main directory:

npm run api
